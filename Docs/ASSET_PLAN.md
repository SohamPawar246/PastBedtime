# Past Bedtime: asset plan

Every asset the GDD needs, where it comes from, and whether it's in the project yet.
Researched 2 Oct 2026 (jam Hour ~4). Rule check: only **free** assets licensed **CC0, CC BY,
SIL OFL, or AI-generated (disclosed)**. Nothing from paid tiers or marketplaces. Every
third-party file goes into `CREDITS.md` and onto the itch.io page.

**Staging folder:** `C:\Dev\unity\PastBedtime_AssetSources\` holds the downloaded packs,
outside the repo. Import only the files you use into `Assets/`, so the build stays small.

Legend: ✅ in the project · 📦 downloaded to staging · ⬇️ download it yourself · 🛠️ build it · ❌ avoid

---

**What the free tiers actually contain** (checked, not guessed):

- **Base Characters Standard has 2 bodies (male and female) and 5 hairstyles.** The GDD
  assumed the Superhero body; that one is in the paid Source tier ($19.99), which is
  **forbidden**. Plan instead:
  - **Max** = male base with a cape quad, the bolt decal and slightly scaled chest/shoulder bones.
  - **Inkies** = male base in flat black with white eyes.
  - **Bruiser** = male base at ×1.4.
  - **Mom** = female base, unlit black.
- **Animation Library 1 Standard has 46 clips**, read from the CC0 mirror
  [J-Ponzo/gltf-universal-animation-library](https://github.com/J-Ponzo/gltf-universal-animation-library).
  The useful ones:
  `Idle_Loop, Walk_Loop, Jog_Fwd_Loop, Sprint_Loop, Jump_Start, Jump_Loop, Jump_Land, Punch_Jab,
  Punch_Cross, Punch_Enter, Roll (dodge), Hit_Chest, Hit_Head, Death01, Interact (Mom's light switch),
  PickUp_Table (grab), Idle_Torch_Loop, Crouch_Idle_Loop, Push_Loop`.
- **Animation Library 2 Standard has 42 clips**, including `MELEE_HOOK` + `MELEE_HOOK_REC`
  (use for the haymaker), `KNOCKBACK`, `JUMP_LAND`, `SLIDE`.
- **No kick in any free tier.** Choose one:
  1. Key a 3-pose kick on the Humanoid rig in Unity's Animation window (~20 min).
  2. Use `MELEE_HOOK` for both moves.
  3. Use a short procedural leg swing on an IK target.

  Option 1 is the cleanest.
- Both libraries share one humanoid rig, so the clips play on the Quaternius bodies with no retargeting.

❌ **Mixamo.** Its licence forbids redistributing the raw files, and this jam requires a public repo.
❌ **Quaternius Pro or Source tiers** are paid, so they're out.
